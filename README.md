# E-commerce SQL Analysis

## Project Overview

This project analyses an e-commerce database using SQL to answer practical business questions about revenue, profit, products, customers, regions, sales channels and monthly performance.

The database contains four related tables:

- `customers`
- `products`
- `orders`
- `order_items`

## SQL Skills Demonstrated

- SELECT
- JOIN
- GROUP BY
- ORDER BY
- COUNT DISTINCT
- SUM
- ROUND
- LIMIT
- Date analysis with `strftime()`
- Multi-table joins
- Business KPI calculation

## Business Questions

1. What are total revenue, total profit, total orders and average order value?
2. Which five products generate the most revenue?
3. Which categories generate the most revenue and profit?
4. Which customer segment generates the most revenue?
5. Which region generates the most revenue?
6. What is the monthly revenue trend?
7. Which customers spend the most?
8. Which sales channel generates the most revenue?
9. Which products have the highest profit margin?
10. Which month generated the highest revenue?

## Key Findings

- Total revenue: **$1,029,148.50**
- Total profit: **$425,678.54**
- Total orders: **1,200**
- Average order value: **$857.62**
- **Laptop** generated the highest product revenue at **$337,778.70**
- **Technology** was the highest-performing category by revenue and profit
- **Consumer** was the highest-revenue customer segment
- **West** was the highest-revenue region
- **Online** was the highest-revenue sales channel
- **Bookshelf** had the highest profit margin at **43.33%**
- **2024-01** was the highest-revenue month at **$76,321.18**
